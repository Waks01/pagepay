## 🔧 Technical Requirements: Live Task Notification Engine

### **The Challenge:**

Services like **Live Stream Viewers** cannot rely on passive task browsing. Users must join within 5 minutes of the livestream starting, or the sponsor loses the "social proof" effect.

### **Solution: Real-Time Push Notification System**

**Architecture:**

1. **Firebase Cloud Messaging (FCM)** for push notifications
2. **Geolocation targeting** (notify users in sponsor's region first)
3. **User availability scoring** (notify active users who respond fastest)
4. **Drip delivery algorithm** (stagger notifications to avoid Meta detection)

### **How It Works:**

**Step 1: Sponsor Creates Urgent Task**

- Sponsor: "I'm going live in 5 minutes, need 50 viewers for ₦50 each"
- Total budget: ₦2,500 (50 viewers × ₦50)
- Funds go into escrow immediately

**Step 2: Intelligent User Selection**

- System identifies 100 eligible users (2x cushion)
- Prioritizes: Active now + Fast responders + Good rating + In same timezone
- Segments users into waves (Wave 1: 50 users, Wave 2: 25 backup, Wave 3: 25 backup)

**Step 3: Staggered Notification Delivery**

- **Minute 0:** Notify Wave 1 (50 users)
  - Push: "🔴 URGENT: Join live stream NOW! Earn ₦35 for 15 mins. Tap to claim."
- **Minute 2:** If <30 accepted, notify Wave 2 (25 backup users)
- **Minute 4:** If still <50, notify Wave 3 (25 backup users)

**Step 4: User Joins & Verification**

- User taps notification → Deep link opens task details
- User clicks "Accept Task" → Opens Facebook livestream link
- User stays for 15 minutes (system tracks via periodic screenshot capture)
- User submits screenshot proof showing 15+ min watch time

**Step 5: Payout & Rating**

- System verifies screenshot timestamp
- If valid → User earns ₦35, PagePay keeps ₦15
- If user joined late or left early → No payment
- User and sponsor rate each other

### **Anti-Detection Algorithm (Avoid Meta Flags):**

**Problem:** If 50 users join a livestream within 30 seconds, Meta's bot detection might flag the sponsor's page.

**Solution: Natural Drip Delivery**

```
Viewer Join Timeline (Example):
- Minute 1-2: 8 viewers join (appears natural)
- Minute 2-3: 12 viewers join (building momentum)
- Minute 3-5: 15 viewers join (peak interest)
- Minute 5-7: 10 viewers join (sustained interest)
- Minute 7-10: 5 viewers join (late arrivals)

Total: 50 viewers over 10 minutes = Natural growth curve
```

**Implementation:**

- System assigns each user a random "join window" between 0-10 minutes
- Notification says: "Join anytime in next 10 minutes"
- System tracks and pays based on when user actually joined
- Creates natural-looking viewer influx pattern

### **2. Retention & Clawback:**

**For retention-based tasks (follows, joins):**

- User completes task → Money goes to escrow
- System checks after 7 days → Still followed/joined?
- **YES:** Money released to user wallet
- **NO:** Money clawed back, user account flagged
- **3 violations:** Account suspended

---

### **3. Fraud Prevention:**

**User Verification Levels:**

- **Level 1 (Basic):** Phone verification → Access to ₦5-15 tasks
- **Level 2 (Verified):** Phone + NIN/BVN → Access to ₦20-50 tasks
- **Level 3 (Premium):** Level 2 + 50 completed tasks + 4.5★ rating → Access to timeline posts (₦105-210)

**Registration Fee:**

- ₦1,000 one-time activation fee
- Prevents fake accounts / multi-accounting
- Funds initial escrow pool
- 50% refunded after 100 completed tasks

- Must be relevant to post content

- AI + human review

**Reviews:**

- Minimum 20 words

- Must be constructive feedback
- Human review required

## 💡 Unit Economics

### **Per Task Economics:**

**Revenue (30% of sponsor payment):**

- Post Like: ₦1.50
- Page Follow: ₦3.00
- Comment: ₦6.00
- Average: ~₦3.60

**Costs:**

- Payment processing (Paystack 1.5% + ₦100 cap): ~₦0.08/task at scale
- Server/infrastructure: ~₦0.05/task
- Fraud detection/review: ~₦0.10/task
- Customer support: ~₦0.05/task
- **Total costs: ~₦0.28/task**

**Net Profit Margin:**

- Gross: ₦3.60
- Costs: ₦0.28
- **Net: ₦3.32 per task (27.7% net margin)**

**At 30M tasks/month:**

- Gross revenue: ₦108M
- Costs: ₦8.4M
- **Net profit: ₦99.6M/month**

✅ **Highly profitable at scale!**
