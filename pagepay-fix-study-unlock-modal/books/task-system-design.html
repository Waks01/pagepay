• Submission history /tasks/history.tsx
• Worker profile /tasks/profile.tsx
• Navigation structure
• Backend /api/v1/tasks/*
• API types in src/features/tasks/api.ts
🔧 Extend / Add
• Add task category: "social" vs "survey"
• Add reward display: points for all tasks
• Admin task creation flow
• Admin review dashboard
• Task list category filter
• Visual treatment for engagement tasks
• Points credit logic
6. Data Model Changes
Field Existing New / Extended Notes
task_type survey, video, app_install + engagement New type for admin tasks
category — "social" | "survey" NEW FIELD — user-facing filter
reward_amount In naira (cents) Points for all tasks Unified display
time_limit_minutes 10, 30, 60... NULL for engagement No time limit for social tasks
min_worker_level 1, 2, 3... 0 or NULL for engagement Open to all users
status (submission) pending, validating, approved, rejected Same — skip validating Engagement tasks go straight to pending
Note: Admin-created tasks reuse the same tables. No new tables required.
7. Missing Screens to Build
1. Admin task creation: Extend existing sponsor form or create new admin form. Same fields, different defaults.
2. Admin review queue: New screen at /admin/tasks/submissions. Table of pending submissions with screenshot preview, user info, approve/reject actions.
3. Admin submission detail: Click a submission to view full-size screenshot, user details, task details, rejection reason input.
4. Task list filter: Add category filter pills to /(tabs)/tasks.tsx: All / Social / Survey / Video.
5. Points notification: Toast/in-app notification when points are credited after admin approval.
